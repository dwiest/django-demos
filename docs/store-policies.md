# Customer policies

Apply migration 0013 before deploying. Public Shipping, Returns, Privacy, Terms,
and Contact pages are linked from every store footer. Store Settings provides
plain-text overrides; blank fields use the generic starting statements. The store
name and contact email come from existing branding settings. Configure the email
before accepting orders. HTML in policy overrides is escaped.

The starting shipping policy uses 3 business days for in-stock processing, separate
item estimates for production, US-only shipping, checkout charges, tracking when
available, and delay consent or cancellation/refunds. It does not select a supplier
or require direct fulfillment. Keep item estimates and the existing shipping
estimate setting consistent with the policy.

Returns exclude change-of-mind refunds, offer refunds or agreed replacements for
problem items, and require contact before sending returns. Saleable returns are
discretionary; no store-credit balances, redemption, automated returns, replacement
workflow, or payment-provider refund processing is added. Existing checkout is
simulated. Privacy and terms are starting copy that must be reviewed against actual
providers and practices before live sales. Policy revisions are not archived against
orders in this initial implementation.
